교정이 표 **머리의 규칙**을 강화했다면, 그 표의 **모든 행**을 새 규칙으로 다시 도출했는지 확인한다. 한 행만 고치고 규칙을 바꾸면 나머지 행이 조용히 거짓이 된다.

**Why:** t9 계획 감사 3회차. 변이표 머리를 "각 변이는 기준 **하나만** 무너뜨려야 한다"에서 "실패 기준 집합이 칸과 **정확히 일치**해야 한다"로 강화하면서 A 행만 다시 도출했다. D 행(적힌 집합 2건, 실제 4건)과 E 행(1건 vs 2건)이 새 규칙 아래 거짓이 됐고, DoD 가 전건 집합 일치를 이분법으로 요구하므로 run 이 그 항목을 참으로 만들 수 없게 됐다. 앞선 두 라운드가 쫓던 "본체를 고치고 측정 자리를 따라가지 않는" 형태가 **교정 자체에서** 재생산된 것이다.

**How to apply:** 감사 중 「규칙 문장이 바뀐 표/목록」을 보면 행 단위로 전건 재검증한다. 특히 (a) 완화 → 강화 방향일 때, (b) 표의 칸이 다른 문서의 기준을 참조할 때(형제 SPEC 기준이 섞인 칸은 본문을 열어 단언까지 읽는다). 관련: [[criteria-outside-the-regression-suite]], [[correction-may-not-cover-whole-card]]
