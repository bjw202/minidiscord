# Discord 디자인 분석 (Design DNA)

사용자가 제공한 Discord 앱 스크린샷(다크 테마, 전체 레이아웃)을 분석한 결과입니다. `web/design-tokens.css`가 이 문서의 값을 그대로 CSS 변수로 옮긴 실제 파일이고, M5(웹 UI) 작업은 이 토큰을 그대로 갖다 쓰면 됩니다.

> **정확도 안내**: 스크린샷을 눈으로 보고 색을 추정한 것이라, Discord 공식 디자인 시스템에 알려진 값과 대조해 보정했습니다. 픽셀 단위로 색을 뽑아낸 것은 아니라서 ±소폭 오차가 있을 수 있어요. 모션(호버 애니메이션 속도 등)은 정지 이미지라 관찰할 수 없어 "관찰 안 됨"으로 표시했습니다.

## 1. 색상 (`design_system.color`)

레이어가 4단으로 나뉘는 게 Discord 다크 테마의 핵심이에요 — 왼쪽으로 갈수록 어둡습니다.

| 역할 | 값 | 어디 쓰임 |
|---|---|---|
| 서버 아이콘 레일 배경 | `#1e1f22` | 맨 왼쪽 원형 아이콘 줄 |
| 채널 사이드바 배경 | `#2b2d31` | "모두의 AI" 채널 목록, 멤버 목록도 동일 |
| 채팅 영역 배경 | `#313338` | 메시지가 보이는 메인 영역 (가장 밝은 회색) |
| 메시지 호버 배경 | `#2e3035` | (스크린샷엔 안 보이지만 Discord 표준값 — 관찰 안 됨, 표준값 차용) |
| 기본 텍스트 | `#f2f3f5` | 메시지 본문 |
| 흐린 텍스트 | `#949ba4` | 타임스탬프, 채널 카테고리 라벨 |
| 브랜드 강조색(블러플) | `#5865f2` | "앱" 뱃지, 링크, 포커스 링 |
| 온라인 상태 | `#23a55a` | 초록 점 |
| 자리비움 | `#f0b232` | (스크린샷엔 없음 — 표준값 참고) |
| 방해금지 | `#f23f43` | (스크린샷엔 없음 — 표준값 참고) |
| 구분선 | `#3f4147` | 날짜 구분선, 사이드바 경계 |

**역할명 색상**(중요한 특징): 사용자 이름이 역할에 따라 각각 다른 색으로 표시돼요(주황 "AI.Latte", 초록 "모두의 AI 공장장", 핑크 "뽀로로는내우상"). 단색 하나가 아니라 **역할별 팔레트**입니다. minidiscord는 봇마다 다른 색을 배정하는 정도로 가볍게 반영하면 충분해요.

`palette_type`: 단색조 배경(모노크롬 그레이 스케일) + 포인트 컬러 하나(블러플) — "monochromatic + single accent"
`contrast_strategy`: light-on-dark dominant (어두운 배경에 밝은 텍스트)

## 2. 타이포그래피

- **폰트**: 휴머니스트 산세리프(Discord 자체 "gg sans" 계열). 우리는 시스템 폰트 스택으로 대체: `-apple-system, "Segoe UI", "Noto Sans KR", sans-serif` (한글 지원 필수라 Noto Sans KR 포함).
- 메시지 본문 ~15px, 일반 굵기
- 사용자 이름 ~15px, 세미볼드 + 역할 색상
- 타임스탬프 ~12px, 흐린 텍스트색
- 채널 사이드바 카테고리 라벨: 11px, 대문자, 자간 넓음, 흐린 텍스트색

## 3. 간격 (`spacing`)

- **기본 단위**: 4px 배수 체계로 보임 (8/12/16/20px 간격이 반복 관찰됨)
- **밀도**: comfortable (compact는 아님 — 메시지 사이 여백이 넉넉한 편)
- 같은 사람이 연속 메시지를 보내면 세로 간격이 좁아지고(그룹핑), 새 사람이 시작하면 아바타+이름이 다시 나오며 간격이 넓어짐 — **이건 minidiscord 채팅 화면에서 꼭 살릴 가치가 있는 패턴**이에요.

## 4. 모양 (`shape`)

- **아바타·서버 아이콘**: 완전 원형(`border-radius: 50%`)
- **메시지 입력창**: 큰 둥근 사각형, 대략 8px radius (알약 모양까지는 아님)
- **뱃지("앱" 태그)**: 작은 둥근 사각형, ~4px radius
- **테두리 사용**: `subtle 1px` — 굵은 테두리 없음, 구분선만 얇게

## 5. 레이아웃

4단 컬럼 구조:

```
[서버 아이콘 레일 ~72px] [채널 사이드바 ~240px] [채팅 영역 (가변)] [멤버 목록 ~240px]
```

상단에 채널 헤더 바(아이콘들 + 검색창), 하단에 메시지 입력 바(둥근 입력창 + 아이콘 버튼들).

## 6. 아이콘 / 엘리베이션

- **아이콘**: 라인 스타일, 얇은 획, 작은 크기(~20px)
- **그림자(elevation)**: 거의 없음 — 플랫 디자인. `shadow_style: none` (모달류는 스크린샷에 없어 관찰 안 됨)

## 7. 시각 효과 (`visual_effects`)

이 화면에는 파티클·3D·셰이더·글래스모피즘 등 특수 효과가 전혀 없습니다. `effect_intensity: none`, 전 카테고리 `enabled: false`. minidiscord도 이런 효과 없이 순수 CSS로 충분합니다.

## minidiscord에 적용할 때 조정 포인트

- **컬럼 수는 3개로 단순화**: minidiscord는 서버 개념이 없으니 "서버 아이콘 레일"은 뺍니다 → [방 목록 사이드바] + [채팅 영역] + (선택) [봇 상태 패널]. `spec.md`의 2단 레이아웃(사이드바+채팅)과도 맞습니다.
- **역할 색상 → 봇 색상**: 봇마다 이름 색을 다르게 주면 "누가 말했는지" 한눈에 구분되는 Discord의 핵심 가독성을 그대로 가져올 수 있어요.
- **메시지 그룹핑 패턴**은 꼭 반영 추천 — 같은 사람 연속 메시지는 아바타 생략하고 간격만 좁혀서, 봇 응답이 길어져도 화면이 덜 산만해집니다.

## 참고 파일
