## 5. 이 카드가 run 중에 발견한 것 (후속 카드 참조용)

1. **AC-E2E-013 측정 ③ SPEC 결함** — 컨텍스트 행 계수로 커밋 뒤 무조건 빨강(D-02의 쌍대). 리드 승인 아래 manager-spec 재위임으로 정정(`346a077`, spec.md v0.3.2).
2. **골격의 env 주입 누락** — `MINIDISCORD_BOT_FILES_DIR`(config.ts:13 fail-closed) 누락을 레인 재현이 포착, 커밋 전 보완(M2 ⑧⑨ 예방).
3. **정적 import가 의존성 부재 계약을 깸** — 늦은 적재로 복원(M2).
4. **`transport-auth.test.ts` flaky 2회 관측** — «both nonces are regenerated…» (M3 스위트 1회·M6 커밋 게이트 1회 — 게이트가 실제로 한 번 막았다). 관측 사이의 실행과 단독 재실행은 전부 초록(마지막: `channel-retry.log` 95 passed). **t27(CI 배선)이 알아야 함.**
5. **`./data` 생성 시험 7종** — health·permissions·web-* 등이 스위트 실행 시 `./data` 생성(기존 행동, 이 카드 범위 밖) — **t27 참조.**
6. **`stopServer` 생략 시 러너 미종료** — 변이 C로만 관측된 성질. `child.unref()` 후속 후보(이 카드에서 고치지 않음).
7. **README t23 언급 3→4** — 트리거 첫 줄이 정본 문면으로 t23을 언급(계획된 추가) — t23 관련 후속 카드 참조.
8. **«서비스화한 배치에서» 문언** — 자연독 개선 후보, 리드 판정으로 N3 이월 후보로만 기록(t6은 정본 글자 충실 유지).

## 6. Gaps와 Residual-risk

- 재시작은 SIGTERM 경로만 재었다 — SIGKILL 직후 WAL 복구는 미측정. ⑭ 동일성 표적은 1메시지·1첨부·1토큰(REQ-E2E-008 요구 셋은 충족). ⑬ 재전송 프레임의 전선 내용은 미관측(커서 상승 증거 사슬 — 변이 B가 그 사슬의 유효성을 뒷받침).
- 모든 초록은 이 나무·무부하 환경 값 — 부하 내성 미시험. transport-auth flaky는 원인 제거가 아니라 미재발.
- 과도기 어긋남(트리거 ㉠ «사내망 전용» vs README 3·190행 «내 PC»)은 **공시된 t26 이월** — 이 카드의 미결이 아니다.
