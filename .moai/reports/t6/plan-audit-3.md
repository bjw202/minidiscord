## 2. N-01 — 부류로 닫혔고, **새 위험을 들이지 않았다** (코디네이터 질문 ②)

리터럴화의 이론적 위험은 「기준선이 실제로 존재하는지 아무도 안 재게 되는 것」이다. 두 기준을 축자로 읽어 확인했다:

**2회차에 지적한 정확한 비대칭 — 011 에는 가드가 있고 013 에는 없다 — 이 해소됐다.** t26 울타리(두 카드 충돌 방지)가 이제 실제로 선다.

$ grep '^- 측정' acceptance.md | grep -c 'BASE'

## 3. N-02 — **못박은 값 「7」은 참이다** (코디네이터 최우선 질문 ①)

레인이 제기한 가설(단순 검색 11 vs 못박은 7)을 **도메인 술어로 확인했다.**

### 개정자가 정의한 술어를 그대로 명령으로 옮겨 실행

술어: 「표지의 출현」이 아니라 **「금지어 패턴에 걸리는 줄 중 면제된 것」**.

```
$ grep -rE "수동 검증(을)? ?(수행|완료)|실 세션으로 (확인|검증)|사람이 (직접 )?확인했" \
    README.md .moai/specs/SPEC-E2E-001/ | grep -c 'AC-016-EXEMPT'
7
```

**7 이 나온다.** SPEC 축자 명령(`scripts/` 포함)으로도 확인:

```
$ grep -rE "<같은 패턴>" README.md scripts/ .moai/specs/SPEC-E2E-001/ 2>/dev/null | grep -c 'AC-016-EXEMPT'
7
```

### 파일별도 못박은 값과 **전건 일치**

$ grep -c 'AC-016-EXEMPT' spec.md → 3

## 4. N-03 — **실행으로 우회 시험했다. 차단된다** (코디네이터 질문 ③)

개정자가 「우회 시도로 시험하지 않았다」고 미검증에 적었다. **감사가 실제로 시험했다** — SPEC 산출물은 건드리지 않고 스크래치 사본에 우회를 넣었다.

```
$ cp README.md $S/bypass/README.md
$ echo '- 실 세션으로 확인했습니다. [AC-016-EXEMPT]' >> $S/bypass/README.md

# 측정 ① (v0.2.0 에도 있던 것) — 우회가 통하는가?
$ grep -rEn "<패턴>" $S/bypass/README.md | grep -v 'AC-016-EXEMPT'; echo "exit=$?"
exit=1          ← 적중 없음 = 초록. 우회 성공

# 측정 ①-c (v0.3.0 신설) — 잡는가?
$ grep -rc 'AC-016-EXEMPT' $S/bypass/README.md
…/bypass/README.md:1     ← 0 이 아니다 = 빨강. 우회 차단
```

**우회는 측정 ①을 통과하지만 측정 ①-c 에서 빨개진다.** 2회차에 지적한 통로가 실제로 막혔다 — 논리가 아니라 **관측**이다. 세 라운드를 통틀어 실행으로 검증된 첫 기준이다.

산문으로만 있던 규약(「README 와 `scripts/` 에는 면제 표지를 쓰지 않는다」)이 측정으로 내려왔다. **N-03 CLOSED.**

- **고칠 것**: 행7 의 값을 `3` → `6` 으로 고치는 것으로는 부족하다(다음 편집에 또 어긋난다). 값 축과 같은 처방을 적용하라 — 예: 「§7.3 을 제외한 규범 절에서의 적중」으로 범위를 좁히되 **그 제외가 명령 안에 있어야 한다.** 그리고 판정 열의 열거를 실물(`:25`·`:44`·`:54`)로 고쳐라.

### P-02 — [Medium] §7.3 행1 은 **적은 명령이 적은 값을 내지 않는다** (범위 불일치)

- 자리: `spec.md` §7.3 행1
- SPEC 이 적은 것: `grep -rn '/13\]' .` → **`0`** · 판정 「파일 전체에도 0 — 완전 소멸」

## 10. 검증하지 않은 것 (Gaps)

- **[실행 불가] 여전히 E2E·서버·vitest 를 돌리지 못했다.** `ls node_modules` → `No such file or directory`; `ls -d server/node_modules` → 없음. **세 라운드 모두 정적 판독**이며, 이 회차도 예외가 아니다.
- **[이번 회차에 실행한 것]** 읽기 전용 grep/sed 전부, `git diff`/`git rev-parse` 계열, 그리고 **N-03 우회 시험**(스크래치 사본 대상 — SPEC·README 원본은 건드리지 않았다). 새 기준의 측정 명령 중 실제로 돌린 것은 **문서 대상 grep 뿐**이며, 코드·프로세스를 겨눈 측정(AC-001·003·004·006·007·008·009·010)은 **하나도 돌리지 못했다.**
- **AC-E2E-006 의 점유자 확보 블록을 실행하지 않았다** — `node -e` 로 포트를 잡는 형태가 이 환경에서 동작하는지, `sleep 1` 이 충분한지 확인하지 않았다(P-06). 개정자도 같은 Gap 을 공시했다.
- **`openDb(':memory:')` 변이는 1회차 D-15 이래 세 라운드 연속 미검증이다.** 신규 재시작 시험만 빨갛게 하는지 스위트 전반인지 여전히 모른다. DoD 2항이 run 단계에서 기록하게 했을 뿐이다.
