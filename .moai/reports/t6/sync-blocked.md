## 0. 쉬운 말 요약

t6 이 만든 검사 16개 중 15개는 제가 직접 돌려 초록을 확인했습니다. 하나가 빨갛습니다.
그 하나는 「‘수동 검증을 했다’는 문장이 산출물에 하나도 없어야 한다」는 검사인데, run 레인이
걸린 문장 하나를 고친 다음 **그 고친 사실을 적은 기록이 금지 문구를 인용**하면서 새로 걸렸습니다.
고치는 순간에는 초록이었고, 고쳤다고 적는 순간 다시 빨개진 것입니다. 내용상 거짓 주장은
아니지만, 이 검사는 SPEC 이 «무조건» 이라고 못박은 검사라 예외가 없습니다.

## 1. 차단 (Blocking) — 1건

### B-01 · AC-E2E-016 측정 ① 이 인도된 트리에서 빨강

- **주장(run-done §2 016 행)**: 「① exit=1(문언 조정 처분 뒤 재실행)」
- **인도된 트리 실측**:

```
$ grep -rEn "수동 검증(을)? ?(수행|완료)|실 세션으로 (확인|검증)|사람이 (직접 )?확인했" \
    README.md scripts/ .moai/specs/SPEC-E2E-001/ | grep -v 'AC-016-EXEMPT'; echo "exit=$?"
.moai/specs/SPEC-E2E-001/progress.md:195:- **AC-E2E-016 전건**: ① 은 스폰 실행에서 **적중 1건** — `progress.md:69`(레인 소유 결정 요약 행)의 «수동 검증 수행» 문언이 ...
exit=0
```

  기준이 요구하는 값은 `exit=1`(적중 0). 관측은 `exit=0`(적중 1).
- **적중 줄 귀속**: `git log -L 195,195` → **`8f4d273`** (M6 커밋). 즉 «① 재실행 exit=1» 을 적은
  그 커밋이 동시에 새 적중을 실었다 — 재실행 시점에는 참이었고 인도 시점에는 거짓이다.
- **DoD 영향**: acceptance.md §C DoD 1 은 「AC-E2E-001~016 **전건 통과**」를 요구한다. 전건이 아니다.
- **부류**: 이 저장소가 이미 기록한 «정정이 스스로 낡은 기록을 남긴다»
  (`correction-leaves-its-own-record-stale`) 의 재현. spec.md:54 가 v0.3.0 에서 **같은 부류를
  명제 축에서 겪었다**고 스스로 적고 있다 — 이번은 값 축에서의 세 번째 재현이다.
