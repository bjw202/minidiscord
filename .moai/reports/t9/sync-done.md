## 1. 주장 (Claim)

리드 디스패치가 넘긴 인계 4건을 전건 처리했고, 독립 감사가 두 라운드에 걸쳐 찾은 차단 발견 4건(F-A1·F-A2·F-A9·F-B1)과 optional 1건(F-B2)을 전건 종결해 **PASS** 판정을 받았다. **차단 발견은 모두 문서 결함이었고 코드는 한 줄도 바뀌지 않았다.**

**이 종결은 F-01 의 종결이 아니다.** 요구사항 13개가 완료·감사된 것이며, 소켓에서 읽은 진짜 `request_id` 로 판정을 위조하는 Critical 급 잔여를 포함한 셋은 열린 채 카드 `t15` 소유다. 감사자 표현 그대로 — 이 PASS 는 «정직하게 인계했다» 에 대한 판정이지 «막았다» 에 대한 판정이 아니다.

### 2.2 감사 1차 — FAIL, 차단 3건 (`sync-audit.md`, HEAD `2c9a484`)

가중 조화평균 78.0 · Functionality 88 / **Security 62 (must-pass 미달)** / Craft 86 / Consistency 78.

핵심 반증은 프로브 P-A 다. 발신 집합 대조는 `request_id` 를 **모르는** 상대만 막는데, 이 위협 모형의 공격자는 전송 계층 그 자체라 같은 소켓으로 나가는 `permission_request` 프레임에서 진짜 id 를 읽는다.

```
PA_GATEWAY_SAW=["hello","status","permission_request"]
PA_VERDICTS=[{"request_id":"real-42","behavior":"allow"}]
```

- **F-A1 [High][blocking]** — 「승인 판정 주입은 닫혔다」 는 경계 진술이 거짓. `spec.md` §1 이 이 사실을 이미 적었는데 같은 파일 §5 가 반대로 선언 — **문서가 자기 자신과 모순.**
- **F-A2 [High][blocking]** — 중계 시 id 를 지우므로 **먼저 도착한 판정이 이긴다.** 위조 `allow` 뒤 120ms 에 보낸 사람의 진짜 `deny` 가 `PA_VERDICTS` 에 없다. 문서는 `deny`→`allow` 방향만 적었고, 더 나쁜 반대 방향은 어디에도 없었다.
- **F-A9 [Medium][blocking]** — §E.4 미발행, 머리 표 상태 두 단계 정체.

변이 재검증 A·C·D·E 는 전부 표와 일치했고, sync 가 정정한 C 행 `{003(나)}` 는 **옳다**고 확인됐다. 전송 판정 우회는 URL 28형태를 훑어 **찾지 못했다** — 그 방어는 튼튼하다.

## 3. 기준선 귀속 (Baseline-attribution)

모든 측정은 이 트리(`.claude/worktrees/t9`, `WT-chanperm-gate`)에서 수행됐다. 감사 수치의 HEAD 귀속: 1차 `2c9a484`, 재감사 `3b7d44a`, 확인 패스 `3b7d44a` + 미커밋 작업 트리. 테스트 61/61 은 재감사가 `3b7d44a` 에서 재실행한 값이고, typecheck·커버리지는 1차 `2c9a484` 실측을 소스 블롭 해시 동일성으로 귀속한 값이다 — sync 레인이 재측정한 것은 없다.

**sync 레인 자신이 직접 실행해 관측한 것**은 다음뿐이다: `git diff --stat`·`git status --short`(변경 파일 범위), `grep` 5패턴 잔여 훑기, `head -6`/`grep '^status:'`(plan·acceptance frontmatter 부재), `sed -n '362p'`(F-B1 정정 원문). 나머지 모든 수치는 두 감사 보고서에서 읽어 옮겼다.

## 4. 미검증 (Gaps)

1. **F-B1·F-B2 정정 뒤 스위트·타입 검사·커버리지·프로브 P-A·변이를 재실행하지 않았다.** 유효성은 「수정된 추적 파일이 SPEC 마크다운뿐이고 `channel/` diff 가 빈 출력」이라는 관측에 기대며, 재측정이 아니다.
2. **변이 B·F·G·H 는 1차·2차 어느 감사에서도 실행되지 않았다** — 그 네 집합에 대한 판정 없음.
3. **린터 부재** — 이 워크스페이스에 린트 구성이 없다. Consistency 의 기계 검증은 테스트·git 대조·grep 으로만 이루어졌다. **통과가 아니라 없음이다.**
4. **원격 CI 없음** — 브랜치 미푸시, 이 워크트리가 유일 사본.
5. **`t15` 수령 미확인** — 인계 범위는 산출물 여섯 자리에 기록됐으나 큐 카드 본문과 대조하지 않았다. `moai todo` 에 카드 본문 편집 verb 가 없어 레인이 고칠 수 없다 — **리드 조치 필요**(§6).
6. **`sync_commit_sha` 는 마감 커밋 직후 백필한다** — 자기 커밋을 가리키는 값이라 커밋 안에서 알 수 없다.
7. 카드 `t3`·`t4`·`t5`·`t7` 구역과 다른 SPEC 디렉터리는 범위 밖 — 그 구역의 F-01 서술에 대해 판정 없음.

## 5. 잔여 위험 (Residual-risk)

- **Critical 급 공격이 그대로 성립한다.** 소켓에서 읽은 진짜 `request_id` 로 위조한 `permission_verdict`, 그리고 먼저 도착한 판정이 사람의 진짜 판정을 삼키는 성질. 사칭 채팅 주입·이력 오염과 함께 **카드 `t15`** 소유이며, 실제 방어는 서버 쪽 서명·논스가 필요해 `REQ-CHANAUTH-013` 이 이 카드에 금지한 범위다.
- **AC-CHANAUTH-005 가 `throw` 구현을 잡지 못한다.** 회귀 스위트가 「예외를 던지지 않는다」를 오늘 지켜 주지 않는다. 기준 강화는 테스트 변경이라 run 단계 몫으로 열려 있다(F-A3).
- **미관측 요구 조항 3건** — REQ-004·008·011의 일부 갈래. `t10`/`t11` 이월.
- 128 상한의 실사용 분포 미검증(F-A8, `t15`).
