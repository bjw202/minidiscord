## 4. 카드 종결 정의의 변경 경위 — «실질 종결» → «조건부 종결»

카드 본문(큐)의 제목은 «§1.1 **실질 종결**» 이다. plan 단계에서 그 정의가 낮아졌고, 경위를 여기 남긴다. **큐 제목은 편집하지 않는다** — 편집 verb 가 없고, `done`+`add` 는 id 재발급으로 참조를 깬다(t15 선례). **SPEC 기록이 정본이다.**

1. 1회차 감사가 **중계 공격**(F-01 Critical)을 찾았다. 전사가 전달 가능하므로 중간자는 위조하지 않고 넘기기만 해도 봇 세션을 탈취한다.
2. 처방은 **채널 바인딩** — 서명 전사에 중계자가 전달할 수 없는 값(TLS 익스포터)을 넣는 것. `node:tls` 의 `exportKeyingMaterial` 실재를 레인이 실측했다.
3. **그런데 이 프로젝트 서버는 TLS 를 종단하지 않는다** — `server/src` 내 참조 0건, `Fastify({ logger: false })`(`index.ts:34`) + 평문 `listen`(`:74`). 즉 채널 바인딩은 **현재 어떤 배치에서도 서지 않는다.** 2회차 개정이 이 사실을 찾아냈고 레인이 실측 확인했다.
4. 운영자 결정(2026-08-30): **(a) 기제만 싣는다.** §1.1 은 «TLS 배치 조건부 종결» 로 기록하고, 서버 TLS 종단은 후속 카드 **`t23`**(발급·큐 등록 확인).
5. **배포 경고가 이월됐다**: «t22 를 닫기 전까지 배포 불가» → «`t23`(TLS)을 닫기 전까지 **생산 배치 불가**».

**지금 TLS 없이도 유효한 것과 그렇지 않은 것을 갈라 적는다.**

| 요소 | TLS 무관하게 유효한가 |
|---|---|
| 평문 토큰 제거 | **그렇다** |
| 검증자 저장(읽기 유출에 봇 사칭 불가) | **그렇다** |
| 확립 후 프레임 인증 | **그렇다** |
| **중계 중간자 배제** | **아니다** — 문서상 기제만 있고 실배치에서 열려 있다 |

`AC-GWAUTH2-024` 가 «미바인딩 전송에서 공격자가 이긴다» 를 `isOnline === true` 라는 **양성** 단언으로 매 실행 기록한다 — 누락에 초록이 되지 않는다.

## 6. [필수 기록] 감사관 진단 둘 — Kickoff 게이트에서 운영자가 볼 재료

### 6.1 5세대 결함은 존재했고, 병목은 «목록» 이 아니라 «판독 깊이» 다

이 카드는 네 라운드 동안 하나의 부류와 싸웠다 — **정정이 다음 라운드의 결함을 낳는다**(선행 카드에서 네 라운드 연속 재현).

- 3회차가 **구조로** 대응했다: 서수 → 행 이름, 손 열거 ID 범위 → «전건 − 이름 붙은 예외». **작동했다** — 4차 감사관의 독립 훑기에서 그 부류 적중 **0**.
- 그러나 4세대(H-02)가 **훑기 목록에 없던 부류**(«A 가 B 를 지킨다» 대응 주장)에서 났고, 4회차가 그 부류를 목록에 **더했다.**
- **그런데 5세대(J-01)가 바로 그 새로 더한 부류 안에서 났다.** 즉 «부류 목록을 넓히면 잡힌다» 가설이 반증됐다. 4회차가 자기 공백으로 공시한 미판독 집합 안에 결함이 정확히 있었다.

> **병목은 목록의 완전성이 아니라 판독 깊이다. 다음 처방을 «목록 더 넓히기» 로 잡으면 6세대가 난다.**

이 진단은 run 단계 지시에 반영되어야 한다.

### 6.2 감사관이 스스로 밝힌 판정 취약점 — 통과는 여유 있는 통과가 아니다

`plan-audit-4.md:478` 원문 요지: **Testability 를 0.88 이 아니라 0.75 로 보면 총점은 0.83 이 되어 FAIL 이다.** 감사관이 0.88 을 고른 근거는 «J-02 의 결함은 기준을 이진 판정할 수 있느냐가 아니라 그 관측 표면이 어느 절에도 정의돼 있지 않다는 것» 이라는 루브릭 판단이다. 0.86 은 통과선을 **0.01** 넘는다.

## 7. Gaps (미검증)

- **스위트를 돌리지 않았다.** plan 단계 산출물은 문서뿐이며 구현이 없다. `npm test`·`typecheck` 미실행 — 테스트 개수·형제 하네스 파손 범위에 대해 아무 주장도 하지 않는다.
- **모든 변이 예측은 예측이다.** 변이표의 「실측」 열은 규약대로 **비어 있고**, DoD 가 그 열을 «인용된 증거로 채울 것» 으로 요구한다(예측과의 일치가 아니다 — v1 이 13행 중 7행 어긋나고도 «정확히 일치» 를 DoD 로 요구해 실패한 자리의 교정).
- **F-01 중계 공격은 조항 추론이다.** 구현이 없어 실행 프로브 대상이 없다. run 이 `'oracle'`·relay 갈래를 세우면 그때 실행으로 확정된다.
- **훑기 부류 11 의 37자리를 전건 같은 깊이로 재판독하지 않았다** — 이 부류의 전건 참을 주장하지 않는다(`plan.md` §B-0d 에 기록).
