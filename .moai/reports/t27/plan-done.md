## 6. run 레인이 오독하면 안 되는 것

- **이 PASS 는 계획의 품질에 대한 것이지, CI 가 실제로 붉어질 수 있다는 관측이 아니다.** 원격 관측 4건(AC-CI-005·006·007·010)은 **미관측**이며 run 의 부담이다.
- **AC-CI-006 은 커밋 게이트 우회가 필요하다** — `SKIP_MOAI_PRECOMMIT=1` + 커밋 메시지 공시. 실측 근거: 훅이 `moai gate`(vet+lint+**test**)를 돌려 `exit=1` 로 커밋을 거부한다.
- **흔들리는 테스트의 실패율은 미측정이다.** `channel/test/transport-auth.test.ts:719`. 이 나무의 관측은 초록 4회뿐이고, 「과거 2회 실패」는 **t6 의 승계 기록이지 우리 관측이 아니다** — 감사 3회차 어느 라운드도 t6 원문을 열지 않았다.
- **`server/data`** 가 실체다. 루트 `./data` 를 찾으면 헛짚는다(t6 F-05 경고).
- 새 나무에서 첫 일은 **`npm run build -w channel`** 이다. 문서만 담은 커밋도 게이트에 막힌다.
