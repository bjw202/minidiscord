## ㉡ 추적되는 저장소 파일 — 증분 0 (절대값은 판정선이 아니다)
$ git grep -lE [0-9a-f]{64} -- . :!package-lock.json | wc -l   # 절대값
36
# 기준선(5edd97f)의 적중 파일 수: 36
# 현재(HEAD)의 적중 파일 수:    36
$ comm -13 hex-before hex-after   # 새로 생긴 적중 파일 — 비어야 한다
# 새로 생긴 적중 파일 수: 0

## 양성 대조군 ㉠ — 추적되지 않는 임시 파일
