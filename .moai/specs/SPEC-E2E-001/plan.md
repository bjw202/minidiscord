## §B. 이미 알고 있는 문제

1. **초안이 낡았다.** `plan-v2.md` Task 18 의 스크립트는 v1 악수·평문 프레임 가정·`.mjs` 안의 TS 문법·같은 스코프 `const` 재선언 넷을 안고 있어 **파싱조차 되지 않는다**(spec.md §4). **복사해서 고치는 방식이 아니라, 초안을 시나리오 목록으로만 읽고 새로 쓴다.**
2. **이 워크트리에 `node_modules` 가 없다.** `ws`·`tsx` 가 부모 디렉터리의 `node_modules` 로 우연히 해소된다(spec.md §7.1 측정 4·5). **M1 의 첫 명령이 `npm install` 이고, 그 전에 잰 어떤 값도 증거로 쓰지 않는다.**
3. **`npm run build -w channel` 이 커밋 시 필요할 수 있다.** 이 저장소의 pre-commit 게이트는 `channel/dist` 부재 시 거짓 실패를 낸다는 기록이 있다. E2E 자체는 채널 빌드를 요구하지 않지만(가짜 채널을 쓰므로) **커밋 시점에 필요할 수 있다** — M1 에서 실행으로 확인한다.
4. **정정이 자기 형제를 남긴다.** 이 저장소에서 반복된 형태다 — 한 자리를 고치면 그 사실을 부정하는 다른 자리가 거짓이 된다. **M5·M6 이 어간 재훑기를 작업 항목으로 갖는다**(DoD 6항).
5. **`recordSocket` 은 이 카드에서 쓸 수 없다.** 서버 쪽 소켓을 감싸는 인프로세스 도구이고(`createGateway` 의 `onConnection` 으로만 나온다), E2E 는 서버를 별도 프로세스로 띄운다. `buildServer()` 도 `onConnection` 을 넘기지 않는다. 근거와 대안은 spec.md §3 D1 · §7.1 측정 11.

## §D. 제약

- **D-1** `scripts/e2e.mts` 는 서버 소스(`server/src/**`)를 import 하지 않는다. 실제 프로세스를 띄워 HTTP·WebSocket 으로만 말을 건다 — 인프로세스로 부르면 「실제로 돌려본다」가 아니게 된다.
- **D-2** 반대로 **악수 하네스는 import 한다**(D1 (a)). 하네스는 구현을 부르지 않고 스스로 열쇠를 유도하므로 독립성 축이 유지된다(`server/test/gateway-v2.ts:1-5` 주석).
- **D-3** 포트는 하드코딩하지 않는다. 기본은 빈 포트를 스스로 잡되, **`E2E_FORCE_PORT` 가 있으면 그 값을 그대로 쓴다** — AC-E2E-006 의 Given 을 만들 유일한 수단이다(REQ-E2E-006).
- **D-4** 임시 데이터 디렉터리는 `mkdtemp` 로 만들고, **정상·실패 어느 경로로 끝나든** 지운다.
- **D-5** 재시작 영속성 단언은 동일성으로 쓴다(REQ-E2E-010). 개수 산술 금지.
- **D-6** 인프로세스 회귀 짝은 `server/test/restart-persistence.test.ts` 에 두고 기존 격리 관행을 따른다 — `mkdtempSync` + `afterEach` 정리(`gateway.test.ts:19-24` 형태). **[HARD] 두 번째 `buildServer()` 앞에 `app.db.close()` 를 부른다** — Fastify 의 `close()` 는 `app.db` 를 닫지 않으므로, 빠뜨리면 「두 연결 병존」을 재게 된다(1회차 감사 D-13).
- **D-7** README 는 **고쳐 쓴다**. 새로 쓰지 않으며 기존 절 구조(`## 필요한 것` … `## 문서`)를 바꾸지 않는다.
- **D-8** 진행 표지 `[n/15]` 는 **단언 성공 뒤에** 찍는다(REQ-E2E-007 [HARD]). 앞에서 찍으면 AC-E2E-007 이 공허해진다.
- **D-9** 이 카드는 `server/src/**` 를 **고치지 않는다**. DoD 4항이 기준선 있는 diff 로 그것을 잰다.

## §F. 마일스톤

### M1 — 결정 확정과 골격 (Priority High)

- 리드에게 **D1·D2·D3·D5** 확인을 요청하고 답을 `progress.md` 에 기록한다. **D5 는 이전 판을 뒤집은 결정이라 먼저 묻는다.**
- §C 의 확인 명령을 돌리고 기준선을 기록한다.
- `scripts/e2e.mts` 골격을 만든다:
  - 포트 확보 — `E2E_FORCE_PORT` 우선, 없으면 빈 포트
  - 임시 데이터 디렉터리(`mkdtemp`)
  - 서버 spawn(`npx tsx server/src/index.ts`)
  - `/api/health` **시한 있는** 폴링 → 시한 초과 시 `[boot-timeout]` 출력 + **exit 9**
  - 정리 함수(정상·실패·예외 세 경로 전부)
  - 단계 표지 출력기 `[n/15]` — **단언 성공 뒤에만** 호출
  - 의존성 부재 안내 경로(exit 은 `9` 가 **아닌** 값)
- **끝나면**: 아무 시나리오도 없는 스크립트가 서버를 띄웠다가 정리하고 exit 0 으로 끝난다. **AC-E2E-004·005·006 을 이 시점에 처음 잰다.**

### M2 — 시나리오 본체 (Priority High)

- REQ-E2E-007 의 ①~⑬ 을 순서대로 구현한다. 접속은 `connectV2`, 확립 뒤 프레임은 `innerOf` 로 읽는다.
- **⑥ 음성 대조군**: 별도 `new WebSocket(...)` 하나가 `{type:'hello', token}` 을 보내고, close 까지 수신 프레임 0건임을 단언한다. **`server/test/gateway-v2.ts` 를 편집하지 않는다** — 그 파일은 서버 스위트 전체가 공유한다.
- 각 단계에 표지와 단언을 붙인다(표지는 단언 뒤).
- **끝나면**: AC-E2E-001·002·003·007 을 잰다.

### M3 — 재시작 영속성 (Priority High)

- 스크립트에 ⑭ 재시작 단계를 넣는다: 재시작 **전에** 메시지 id·본문, 첨부 id·바이트 해시, 토큰을 기록 → `kill` → 같은 데이터 디렉터리로 재기동 → 셋을 동일성으로 대조 → v2 재접속.
- ⑮ 방 보관 후 접속 거부 단계를 넣어 15단계를 채운다.
- **인프로세스 회귀 짝** `server/test/restart-persistence.test.ts` 를 만든다: 임시 디렉터리에 `MINIDISCORD_DATA_DIR` 을 걸고 `buildServer()` → 쓰기 → `await app.close()` **그리고 `app.db.close()`** → 다시 `buildServer()` → 세 동일성 대조. **재시작 이후 무관한 메시지를 하나 더 넣고 같은 세 단언을 다시 도는 케이스**를 포함한다(AC-E2E-010).
- **끝나면**: AC-E2E-008·009·010 을 잰다.

## §G. 하지 말 것 (안티패턴)

- **기준선 없는 `git diff`.** 커밋 뒤 항상 빈 출력이라 그 위의 검사는 무조건 초록이다. `2a19d7d..HEAD` 를 붙인다.
- **전역 개수로 「자리마다」를 재기.** `grep -c` 한 번은 「세 자리 각각」도 「세 줄 각각」도 재지 못한다. 자리별 앵커·어간별로 쪼갠다.
- **사전 상태가 이미 충족된 어간을 고르기.** 보안 절의 `t23` 은 사전 상태가 2 라서 아무것도 재지 못했다. 어간을 고를 때 **먼저 사전 상태를 측정한다.**
- **소스 문자열로 프로토콜 동작을 재기.** `grep "'hello'"` 는 D1(a) 아래에서 적중이 0 이다. 전선을 재고, 음성 대조군을 둔다.
- **명령 없는 자기 신고 기준.** 「자기 훑기로 확인한다」는 기준이 아니다.
- **부정 단언으로 실패 경로를 재기.** `exit != 124` 는 아무 이유로 죽어도 초록이다. 양성 표지 + 전용 종료 코드로 잰다.
- **공유 하네스를 변이 대상으로 삼기.** `server/test/gateway-v2.ts` 편집은 서버 스위트 전체를 흔드는 굵은 변이다.
- **초안을 복사해 부분 수정하기.** F-01~F-04 넷 중 셋은 눈에 잘 띄지 않는다(특히 `const after` 중복). 새로 쓴다.
- **개수로 영속성을 재기.** `messages.length + 2` 형태는 무엇이 남았는지 재지 않는다.
- **셸 명령만으로 끝나는 영속성 기준.** E2E 스크립트를 지우면 영속성을 재는 자리가 하나도 남지 않는다 — 그래서 M3 의 인프로세스 짝이 [HARD] 다.
- **`app.db.close()` 없이 재구축하기.** 그것은 재시작이 아니라 두 연결 병존이다.
- **`npm test` 에 E2E 를 밀어 넣기.** 카드 `t27` 의 자리다.
- **`server/src/config.ts` 나 README 「내 PC」를 고치기.** 카드 `t26` 의 자리다(정본 §5).
- **「실 세션으로 확인했다」고 적기. [AC-016-EXEMPT]** 이 카드는 실 세션을 띄우지 않는다.
- **재지 않은 수를 적기.** 다른 나무의 값(283, README 303줄)을 승계하지 않는다.
