## 4. 검증하지 못한 것 (Gaps)

1. **v0.4.0 바이트 기준선이 없다** — SPEC 디렉터리가 git 비추적 상태라 암호학적 diff 는 원리적으로 불가. 「안 바꿨다」의 근거는 (a) 3회차 인용 전부의 내용 일치, (b) 줄 수 산술이 공개 편집으로 정확히 소진, (c) 관측 기계 축자 재실행의 출력 일치 — 세 겹이며, 이는 충분하지만 diff 는 아니다.
2. **시험 스위트·tsc 를 직접 돌리지 않았다**(읽기 전용 제약). N4 의 `tsc` exit 0 은 3회차가 **같은 트리(c1ea5fd)에서** 실측한 값이고, 그 입력이 된 AC 코드 블록의 타입 주석이 불변임을 인용으로 확인했다(baseline 귀속 이월). 이번 회차에 새로 관측한 것은 아니다.
3. **아트보드 캔버스는 여전히 접근 불가**(세션 스크래치패드) — 세 라운드와 동일. §1.1 [HARD] 자립성 요구는 §4 본문이 충족한다.
4. **Playwright 실실행·LOC 추정·AC-015 (4) 의 사후 발동**은 구현 후에만 관측 가능 — SPEC 이 스스로 Gap 기록을 [HARD] 로 요구하고 있다(`plan.md` §E).
