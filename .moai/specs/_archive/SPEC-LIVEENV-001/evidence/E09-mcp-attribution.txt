# 두 관측을 «같은 시각» 에 함께 읽는다 — 하나만으로는 귀속이 서지 않는다.

## ㉠ 전역 항목이 존재하지 않는 경로를 가리킨다
# 관측 시각: 2026-09-06T11:04:39Z
$ python3 -c "... d[mcpServers][minidiscord-channel][args][0]"
/Users/byunjungwon/Dev/my-project-04/minidiscord/.claude/worktrees/t32/channel/dist/index.js
$ test -e "<전역 args[0]>"; echo "exit=$?"
exit=1
# [HARD] 이 값이 exit=0 이면(경로가 존재하면) 이 기준은 통과가 아니라 UNMEASURED 다.
#   두 적재 경로가 구별되지 않기 때문이다. 지금은 exit=1 이므로 대조군이 성립한다.

## 승인 시점 — 첫 기동은 무인으로 붙지 않는다
# [HARD] 봇 디렉터리의 .mcp.json 은 프로젝트 범위 항목이라 첫 사용에 사람 승인을 요구한다
#   (spec.md §1.2 F-12). 이 실행에서도 운영자가 세 확인 창을 처리한 «뒤에» 왕복이 생겼다.
#   승인 전의 왕복 부재는 실패가 아니라 아직 재지 않은 상태다.
# 승인 전 관측(이 회차 기록): principal=pm:api=false:conn=0
$ scripts/live-env.sh status   # 승인 뒤
principal=pm:api=true:conn=1 measured=yes
