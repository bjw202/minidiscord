### AC-012 Then-2 문언 정정 초안 — 조항-구현 어긋남 (2026-09-03, 레인 작성 · 편집은 manager-spec 재위임)

**결함의 성질: 문서 결함이며 코드 결함이 아니다.** 구현은 설계대로 동작한다 — 조항이 **도달 불가능한 관측**을 지정하고 있다.

**어긋남.** `acceptance.md` AC-LIVEVERIFY-012 Then-2 는 이렇게 적는다:
> 위 `curl` 출력에서 그 봇 항목의 **`"online":false`** 가 글자 그대로 읽힌다(보관 전에는 같은 자리가 **`"online":true`** 였다).

그런데 보관은 그 방의 토큰을 **전부 철회**하고(`routes-rooms.ts` 보관 트랜잭션 — 레인 실측: `rooms.archived_at` = `2026-09-03 05:33:13`, `bot_tokens` id 5 `revoked_at` = **같은 초**), 초대 목록 질의는 철회된 토큰을 **아예 나열하지 않는다**:
```
routes-bots.ts  GET /api/rooms/:id/invites
  SELECT t.bot_id, b.name FROM bot_tokens t JOIN bots b ON b.id = t.bot_id
   WHERE t.room_id=? AND t.revoked_at IS NULL ORDER BY b.name
```
그래서 보관 뒤 응답은 **`[]`** 다. **`"online":false` 를 실은 항목은 존재할 수 없다** — 항목이 사라진 뒤라야 false 가 될 수 있는데, 사라지면 읽을 자리도 없다. 조항이 요구하는 문자열은 이 구현에서 **원리상 나타나지 않는다.**

**왜 조항이 이렇게 쓰였나(추정이 아니라 문언에서 읽히는 것).** 조항은 바로 앞줄에서 「「봇이 접속되지 않았다」는 관측 대상이 **아니다** — `online` 필드의 값이 관측 대상이다」라고 못 박는다. 모호한 부정형을 피하려는 **옳은 동기**였다. 다만 그 동기를 실현할 구체물로 고른 것이 **철회 뒤에도 항목이 남는다**는, 성립하지 않는 전제였다.

**정정 방향(초안 — 판정 내용을 약화시키지 않는다).** Then-2 를 다음으로 바꾼다:
> 2. 재접속 시도가 세션 확립에 이르지 못한다. **[관측 대상]** — 아래 셋이 `A12-reconnect.txt` 안에서 함께 읽힌다.
>    - ㉠ **보관 전** ①의 `curl` 출력에 그 봇 항목이 있고 **`"online":true`** 가 글자 그대로 읽힌다.
>    - ㉡ **보관 후** ④의 같은 `curl` 출력이 **`[]`** 다 — 항목 자체가 사라졌다. 보관이 그 방의 토큰을 전부 철회하고(`bot_tokens.revoked_at`), 초대 목록 질의가 `revoked_at IS NULL` 만 나열하기 때문이다.
>    - ㉢ 재접속을 시도한 **새 터미널**이 게이트웨이 접속에 이르지 못한다 — 같은 시각의 `lsof -nP -iTCP:3000 -sTCP:ESTABLISHED` 출력에 그 봇의 채널 접속이 **0건**이다.
> ㉠→㉡ 의 **변화**가 관측 대상이며, 어느 한쪽만으로는 서지 않는다.

**이 정정이 판정을 약화시키지 않는 근거.** 옛 문언은 한 필드의 값 하나를 봤다. 새 문언은 **같은 명령의 전후 차이(㉠→㉡)** 에 **접속 실재의 독립 관측(㉢)** 을 더한다 — 축이 하나에서 둘로 늘고, ㉢ 은 웹 API 를 거치지 않는 **다른 표면**이다. 그리고 거부의 자리도 소스에 있다: `gateway.ts` 의 hello 질의가 `revoked_at IS NULL AND r.status = 'active'` 로 **철회된 토큰과 보관된 방을 같은 한 곳에서** 거른다(REQ-GW-002).

**[HARD] 이 초안은 레인이 쓴 것이며 레인은 `acceptance.md` 를 편집하지 않는다.** 실제 편집은 `manager-spec` 재위임 사안이고, 그때 형제 자리(§3.2 의 「`online` 필드의 값이 관측 대상」 서술, `spec.md` §4 ⑫ 요약, DoD 의 부정형 세 항 규약)를 **처음부터 프롬프트에 실어** 함께 훑어야 한다 — 이 카드에서 형제-자리 누락이 반복해 나온 부류다.
